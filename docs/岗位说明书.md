# Evidence-Trading 岗位说明书

## MarketBot（数据层）

### 基本信息
- **岗位名称**: Evidence-Trading Market
- **岗位类型**: 数据 Bot
- **当前模型**: agnes-2.5-flash
- **数据来源**: 腾讯财经 API + 东方财富 API

### 核心职责
1. **行情查询** — 实时价格、涨跌幅、成交量
2. **K 线数据** — 历史 K 线（最长 2 年）
3. **财务指标** — PE、PB、市值等估值数据
4. **选股扫描** — 全市场筛选标的（中小市值 50-300亿）

### 选股逻辑
```python
# 筛选条件
- 市值范围: 50-300 亿元（中小市值）
- 排除涨停: 涨跌幅 < 9.5%
- 排除 ST: 名称含 ST/*ST/退
- 评分因子: 涨跌幅 (40分) + PE估值 (30分) + 成交量 (30分)
```

### API 接口
| 接口 | 功能 | 示例 |
|------|------|------|
| `/api/picks?n=10` | 选股推荐 | 返回 10 只中小市值股票 |
| `/api/quote/{symbol}` | 单股行情 | 获取指定股票实时数据 |
| `/api/kline/{symbol}` | K 线数据 | 获取历史 K 线 |
| `/api/health` | 健康检查 | 服务状态 |

### 技术架构
```
MarketBot (Python)
├── 数据源层
│   ├── 腾讯财经 API (主要) - qt.gtimg.cn
│   └── 东方财富 API (备用)
├── 处理层
│   ├── 数据解析 (GBK 编码)
│   ├── 市值筛选 (50-300亿)
│   └── 评分计算
└── 输出层
    └── JSON API (/api/picks)
```

## AnalysisBot（分析层）

### 基本信息
- **岗位名称**: Evidence-Trading Analysis
- **岗位类型**: 分析 Bot
- **当前模型**: agnes-2.5-flash

### 核心职责
1. **策略回测** — MA 均线、RSI 反转、动量等策略历史回测
2. **因子分析** — 计算因子得分、排名
3. **绩效评估** — 收益率、夏普比率、最大回撤
4. **报告生成** — 输出结构化回测报告

### 支持的策略
| 策略名称 | 参数 | 信号 |
|----------|------|------|
| MA 均线交叉 | fast=5, slow=20 | 金叉买入，死叉卖出 |
| RSI 反转 | period=14, overbought=70, oversold=30 | 超卖买入，超买卖出 |
| 动量策略 | period=20 | 突破买入，跌破卖出 |

### API 接口
| 接口 | 功能 | 参数 |
|------|------|------|
| `POST /api/backtest` | 执行回测 | symbol, strategy, params |
| `/api/kline/{symbol}` | 获取 K 线 | symbol, days |

1. **持仓监控** — 检查持仓盈亏、风险评分

## DirectorBot（主管层）

### 基本信息
- **岗位名称**: Evidence-Trading Director
- **岗位类型**: 主管 Bot
- **当前模型**: agnes-2.5-flash

### 核心职责
1. **任务分配** — 解析用户指令，分发给 Market/Analysis/Risk 各 Bot
2. **结果汇总** — 整合多 Bot 输出，生成结构化报告
3. **质量控制** — 检查数据源、验证结果、添加免责声明

### 协作关系
```
                    ┌─────────────────┐
                    │  DirectorBot    │  ← 主管（协调 + 汇报）
                    └────────┬────────┘
                             │
            ┌────────────────┼────────────────┐

     ┌──────▼──────┐  ┌─────▼─────┐  ┌──────▼──────┐
     │ MarketBot   │  │AnalysisBot│  │  RiskBot    │
     │   (数据)    │  │  (分析)   │  │   (风控)    │
```
